A one-line joke about office life, set at the most contested square
footage in any office: the shared fridge. I label my lunch "DO NOT
TOUCH — DAVE" and it vanishes before noon, so I relabel it "FREE
SAMPLES — TAKE ONE" and suddenly nobody dares touch it. The punchline
is the kicker — "Marketing works." — the label, not the lunch, was the
product all along.

## Run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (one line, 177 characters).
Deterministic: every run writes byte-identical output. Node 22+,
standard library only, no network.
